# 获取帮助 (Getting Help)

> 本文译自官方文档:[原文链接](https://developers.google.com/edge/mediapipe/framework/getting_started/help)
> 为保持内容与版式一致,图片位置、章节顺序、代码示例均与原页对齐。

## 技术问题 (Technical questions)

如需技术或算法问题的帮助,请访问 [Stack Overflow](https://stackoverflow.com/questions/tagged/mediapipe),从 MediaPipe 社区寻找答案和支持。

## Bug 反馈与功能请求 (Bugs and feature requests)

要报告 bug 或提出功能请求,请在 [GitHub 上提交 issue](https://github.com/google/mediapipe/issues)。

如果您打开了一个 GitHub issue,这里是我们的策略:

1.  它必须是 bug、功能请求或文档方面的重大问题(小的文档修复请直接发送 PR)。
2.  必须填写下面的表单。

**我们制定该策略的原因**:MediaPipe 开发者会响应 issue。我们希望专注于惠及整个社区的工作,例如修复 bug 和添加功能。支持(Support)只对个人有帮助。GitHub 也会在问题提交时通知成千上万的人。我们希望他们看到您是在沟通一个有趣的问题,而不是被转到 Stack Overflow。

### 描述问题 (Describe the problem)

请在此清晰地描述问题。务必说明为什么这是 MediaPipe 中的 bug 或功能请求。

### 源代码 / 日志 (Source code / logs)

请包含任何有助于诊断问题的日志或源代码。如果包含 traceback,请包含完整的 traceback。大型日志和文件应作为附件附加,而不是作为文本粘贴到 issue 中。
